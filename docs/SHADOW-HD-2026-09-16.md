# DOM 그림자와 8배 내루미

**사계절 배경 32장의 고정 그림자를 제거하고, 평소·점프·접근을 같은 DOM
그림자로 연결했다. 근접·정지 내루미 8종은 2304×1984에서 4608×3968로 높였다.**
점프할 때 그림자는 바닥에 남고, 접근할 때는 위치와 원근만 따라온다.
첫 방문·약 5분·뉴트럴 포즈·수동 호출 조건은 유지한다.
8종 전체 용량은 2,079,164바이트(약 1.98MiB)다. 브라우저 24개 검사 모두 통과했다.

## 그림자

`#naeru-shadow`를 `#naeru-move`의 형제로 두어 몸의 수직 이동과 분리했다.
발밑의 작은 접촉 그림자와 뒤로 뻗은 부드러운 투영 그림자를 CSS로 만든다.
캐릭터가 뜨면 접촉 그림자는 작고 옅어지고, 넓은 그림자는 조금 퍼진다.
땅에 닿던 기준점의 Y는 바뀌지 않는다.

접근은 캐릭터와 그림자에 같은 원근 transform을 적용한다. 보폭·기울기는 몸에만
적용하고, 발을 드는 정도에 따라 그림자 농도를 조절한다. 복귀·탭 숨김·정지 모드·
장면 전환에서 초기화한다. 정지 모드와 `act=0`에서도 그림자는 유지한다.
새벽·노을·밤·비에는 길이와 농도를, 겨울에는 푸른 색조를 조절한다.

출발점의 그림자를 임시 잔디로 가리던 `#approach-ground`와 접근 전용
`#approach-shadow`는 제거했다. 배경을 복원한 뒤 DOM 그림자를 항상 표시하므로
방문 시작·끝에서 잔디 덮개가 나타났다 사라지지 않는다.

## 배경 복원

원본 전체 편집 후보는 밝기·디테일 변화가 커서 제외했다. 대신 그림자 주변만
800×400으로 잘라 built-in imagegen으로 잔디를 복원했다. 선택한 원본은
`tools/ground/source/day-repair.png`에 보존했다. 새벽·밤·비의 주변 잔디에
명암을 맞추고 제한한 다각형 안에 합성한다.

`tools/season/repaint.py`가 계절 채색 전에 복원한다. 겨울의 눈 마스크도
그림자가 없는 낮 배경으로 계산하므로 어두운 자국이 되살아나지 않는다.
기존 배경·plate는 캐릭터 누끼의 제작 입력으로 남긴다. 제작할 때마다 저장된
복원본을 읽으므로 다시 생성 비용을 내거나 API를 호출하지 않는다.

선택한 이미지의 최종 프롬프트:

```text
Edit this small 800x400 crop of a softly painted muted meadow. Remove only
the isolated dark horizontal cast shadow across the center (roughly
x=160..600,y=180..245). Continue the same quiet softly blurred olive-green
lawn across that footprint. Preserve the very subdued low-contrast
gray-green palette, overall brightness, surrounding grass and flower
locations, and exact crop framing. Do not enhance the contrast,
sharpness, saturation or lighting. No new flowers, blades, objects, or
shadows in the repair. Return the same image with only that shadow erased
into unobtrusive grass.
```

## 고해상도와 누끼

캐릭터 재생성 요청은 built-in 도구가 `moderation_blocked`로 거절했다.
생성된 캐릭터는 없으며, 사용자가 허용한 로컬 업스케일 경로를 이어 썼다.
OpenAI CLI/API 대체 경로는 API 키와 별도 선택이 필요한 경로이며 사용하지 않았다.

Real-ESRGAN animevideov3의 첫 4배 복원 결과를 2배 중간본에 모아 다시 4배
복원한다. 최종 크기는 원본의 8배다. 두 번째 결과 70%와 첫 결과 확대본 30%를
섞어 선은 선명하게, 면의 명암은 부드럽게 유지한다. 타일과 24px 문맥 여유로
추론 메모리를 제한한다.

원본 알파를 확대하고 0.65 원본 픽셀 반경으로 경계를 연결한 뒤, 넓은 반투명
띠를 좁힌다. 실루엣을 새로 생성하지 않는다. 반투명 외곽선 색까지 교체한 후보는
선이 끊겨 제외했고, 실제 외곽선 색을 보존한 후보를 선택했다.
결과는 `img/naeru-{dawn,day,dusk,night}[-rain]-hd.webp` 8장이다.

영상 전체 316프레임은 기존 해상도이며, 근접 뉴트럴 포즈와 정지 화면이 8배다.
해상도 증가는 원본에 없던 디테일의 정확성을 보장하지 않는다. 원래 그림체와
포즈를 기준으로 밝은 배경·어두운 배경·실제 확대 화면을 비교했다.

제작 명령·모델 해시·라이선스는 [고해상도 도구](../tools/naeru-hd/README.md),
배경 합성은 [잔디 복원 도구](../tools/ground/README.md)에 있다.

## 검증 자료

Chromium의 전체 회귀 검사 **24/24 통과**. 사계절·정지 화면의 그림자,
실제 점프 중 지면 Y 고정과 접촉 농도 복원, 접근 중 원근 일치, 중단·복귀,
첫 방문·5분 주기·뉴트럴 대기·수동 호출·집중 타이머를 확인했다.
런타임 자산 88개·크롭 좌표·자산 판번호·인라인 JS 10개 문법도 통과했다.

알파를 원래 크기로 줄인 실루엣 IoU는 8종 모두 **99.9341%**다.
불투명 영역의 평균 채널 차이는 원본 대비 1.94~5.50/255였다.
이 값은 포즈·색 유지의 확인값이다. 흐림·계단·반투명 테두리는 따로 눈으로 확인했다.

배경 합성의 변경 영역은 원본 좌표 약 x1538–2140, y1624–1827이다.

최대 단일 채널 차이는 4/255였다. 영역 밖 차이는 재인코딩에 따른 미세한 값이다.
