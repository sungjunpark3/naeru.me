# 가을 낮 — 화면 앞으로 다가오기 시범

**맑은 가을 낮에서 내루미가 여섯 걸음으로 다가와 화면을 크게 채우고,
2.4초간 인사한 뒤 제자리로 돌아간다.** 일반 접속에서는 5분마다 방문하며,
집중 종료에도 연결했다. 설정의
`가까이 와줘`로 즉시 시험할 수 있다. 앞꽃과 그림자를 DOM/SVG로 분리했다.
기존 576×496 영상을 확대하므로 근접 화면은 흐릿하다. 실제 다리 보행 영상이
아닌 확대·체중 이동의 합성이며, 이번 범위는 동선과 깊이감을 보는 시범이다.
2026-09-11 사용자의 요청으로 5분 주기 자동 방문을 추가해 배포에 포함한다.

## 보기와 조작

로컬 서버에서 다음 주소를 연다.

```text
/?s=autumn&v=day&w=clear&act=approach&ball=0&flit=0&ff=0
```

- 위 미리보기 URL에서는 첫 장면의 페이드가 끝난 뒤 한 번 재생한다.
- 일반 접속에서는 장면 준비 후 5분마다 방문한다. 실제 접근을 시작한 때부터
  다음 5분을 세며, 다른 행동이나 설정 창이 열려 있으면 기다린다.
- 탭 복귀·풍경 전환·움직임 재개 시 새로 5분을 센다. 숨은 동안의 방문은
  쌓아두지 않는다. 수동 호출이나 집중 종료 방문 뒤에도 5분 간격을 둔다.
- 접근 4.2초 → 가까이서 인사 2.4초 → 복귀 3.4초, 약 10초다.
- 위쪽 `돌아가기`, 내루미 클릭, Escape로 일찍 돌려보낼 수 있다.
- 설정에서도 다시 부를 수 있다. 일반 내루미 클릭은 기존 폴짝 인사를 유지한다.
- 가을·낮·맑음·움직임 허용 조건에서만 제공한다.
- 다른 풍경의 집중 종료는 기존 문구·폴짝 인사를 유지한다. 정지 모드는 문구만
  표시한다. 소리와 시스템 알림은 추가하지 않았다.

## 구현과 복구

`index.html`의 `#naeru-approach`가 원근 이동과 확대를,
`#naeru-stride`가 발걸음별 기울기·상하 움직임을 담당한다.
기존 `#naeru-move` 좌표와 다른 몸짓의 transform은 유지한다.
화면 크기와 눈 기준점으로 끝 위치를 계산하고, 좁은 화면은 얼굴 폭을 제한한다.

앞쪽 꽃은 배경의 동일한 픽셀을 SVG 마스크로 다시 올린다. 분홍·보라색 점수와
밝기를 사용해 꽃잎을 구분하고 갈색 배경을 제외한다. 꽃술과 줄기를 보완하고
하단 풀은 부드럽게 연결한다. 새 래스터 파일을 만들지 않아 자산 80개와
`ASSET_V=3cd0c6104366`은 그대로다. 가을 맑은 낮에 맞춘 마스크이므로 다른
장면에 그대로 켜면 안 된다.

배경에 구워진 출발점 그림자는 근처 잔디를 옮긴 타원형 패치로 가린다.
다가오는 몸 아래에는 별도의 부드러운 그림자를 합성한다. 복귀 때 원래
그림자를 다시 표시한다. 원본 배경 파일은 수정하지 않았다.

집중 종료 이벤트는 공·나비·기존 인사가 끝나기를 기다린다. 부팅 중 종료된
타이머도 장면 준비 후 처리하며, 같은 동작을 중복 예약하지 않는다.
탭 숨김·풍경 변경·화면 크기 변경·OS 동작 줄이기는 transform과 busy/hold를
정리한다. 실행 프레임이 OS 설정 변경을 먼저 읽어도 장면 갱신을 전달한다.
