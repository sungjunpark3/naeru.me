# 2026-09-11 개선 내역

저프레임에서 공 동작이 끝나지 않는 문제, 실행 중 동작 줄이기 전환에서
내루미가 사라지는 문제, 날씨 오류가 성공 캐시를 덮는 문제를 수정했다.
겨울 배경 상단의 흰 띠를 제거하고 설정·첫 방문 힌트·집중 타이머를 추가했다.
브라우저 검사 12개 묶음과 자산 80개·영상 16개 검사를 통과했다.
현재 로컬 변경이며 커밋·push·배포는 하지 않았다.

## 화면과 기능

- 계절·풍경의 시간·움직임·날짜 형식·시계 표시를 저장하는 설정 패널.
- 내루미를 누를 수 있다는 첫 방문 안내와 키보드 Enter·Space 인사.
- 25분·50분 집중 시간, 새로고침 복구, 완료 문구와 인사.
- 즉시 표시되는 서울 시계, 서울 기준 안내, 날씨 갱신 지연 표시.
- WMO 85·86 문구를 `소낙눈`으로 수정.
- 잘못된 CSS 필터 합성 수정, 겨울 배경 8장 재생성.
- 의미 있는 제목·설명, native dialog·포커스 표시·상태 알림·정지 대체 화면.

## 구조와 유지보수

- 장면 변경·탭 숨김에서 각 동작의 타이머와 rAF를 취소하고 상태를 정리한다.
- 비동기 장면 요청을 세대별로 구분하고 영상 실패 시 정지본을 유지한다.
- HTTP 상태와 날씨 응답을 검증한 후 성공 데이터만 한 번에 교체한다.
- 개발 문서·도구·제작 입력에 Netlify 강제 404 규칙을 추가했다.
- 기존 상세 문서를 작업 기록으로 보존하고 현재 구조와 실행법을 분리했다.
- 계절별 부분 재생성, Python 의존성 목록, 자산·좌표·영상 검사 도구를 추가했다.
- 자산 내용 해시를 요청 판번호로 사용해 파일 변경 시 누락을 검사한다.

날씨·시간·탭 숨김은 제어된 조건으로 재현했다. 대표 모바일 설정 화면과
수정한 겨울 배경도 육안으로 확인했다. 전체 캐릭터 재생성 파이프라인은
실행하지 않았고, 겨울 배경 부분 재생성과 제작 스크립트 문법을 확인했다.

## 남은 범위

Netlify 경로 규칙의 실제 HTTP 응답은 배포 후 검증해야 한다.
Safari/iOS 실기기에서 HEVC 알파 재생은 이번에 재검증하지 않았다.
봄·여름 새 원화, 아이콘 재제작, 환경음, 행사 장식은 후속 콘텐츠 아이디어다.
겨울 강수를 눈으로 표현하는 기존 정책과 혀·수련회·낙엽의 기본 비활성 상태는
유지했다. 제작 입력의 HTTP 차단은 물리적인 배포 용량 축소와 별개다.
