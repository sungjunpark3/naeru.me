# DOM 내루미 고해상도 적용

**뉴트럴 내루미 8종을 576×496에서 2304×1984로 4배 복원해 DOM에 연결했다.**
다가올 때 아직 작은 거리에서 고해상도 그림으로 전환하고, 돌아가면 원래
영상 재생을 이어간다. 정지 모드·영상 실패 화면도 준비된 고해상도 그림을 쓴다.
기존 실루엣을 보존했고 8장 전체 용량은 844,670바이트, 약 825KiB다.
첫 방문·약 5분 간격·뉴트럴 포즈 조건과 가을 꽃 레이어는 앞서 배포한 조건을 유지한다.

파일명은 `img/naeru-{dawn,day,dusk,night}[-rain]-hd.webp`다.
모든 이미지가 투명 RGBA이며, 여백·발 기준점·원래 576×496 크롭 비율을 유지한다.
앱이 받는 이미지의 해상도만 높여 기존 좌표 계약을 그대로 사용한다.

재생성 도구인 built-in imagegen은 원본 편집 요청을 두 번 모두
`moderation_blocked`로 거절했다. 새로 그린 결과물은 없다. 사용자가 허용한
업스케일 방법으로 전환해 로컬 Real-ESRGAN animevideov3를 사용했다.
별도의 OpenAI CLI/API를 호출하지 않았다.

Real-ESRGAN의 공식 애니메이션 모델은 4배 복원을 지원한다.
이 프로젝트에서는 압축 전 뉴트럴 프레임 8장을 입력으로 사용했다.
[공식 모델 설명](https://github.com/xinntao/Real-ESRGAN/blob/master/docs/anime_video_model.md)

첫 생성 요청은 기존 캐릭터·포즈·색·배치를 보존하고 2304×1984의 투명
고해상도 그림으로 복원하라는 내용이었다. 두 번째 요청은 다음과 같이 줄였으나
같은 오류로 실패했다. 실제 업스케일은 텍스트 프롬프트를 사용하지 않는다.

## 누끼와 화질

AI가 누끼를 새로 추측하게 하지 않았다. 기존 알파를 고품질 보간하고 RGB만
신경망으로 복원한다. 투명 영역에 남은 잔디 색은 추론 전에 주변 캐릭터 색으로
연장하고, 완전히 투명한 픽셀의 RGB는 저장 전에 지운다.

WebP 저장 후 알파는 보간 결과와 **픽셀 단위로 일치**했다. 원래 크기로
다시 줄여 비교한 50% 실루엣의 IoU는 8종 모두 **99.9842%**다.
불투명 영역 RGB의 평균 절대 차이는 255단계에서 1.51~3.70이었다.
이 수치는 위치·색의 보존 정도이며, 새 디테일이 원본의 정답이라는 뜻은 아니다.

눈·입·배 무늬의 선은 더 또렷해졌다. 원래 누끼의 부드러운 가장자리와 발 모양을
유지했으므로 완전히 새로 그린 벡터처럼 날카로운 경계는 아니다.
특히 큰 화면에서는 원본의 작은 코 선과 굴곡이 복원 과정에서 강조될 수 있다.

## DOM 전환과 로딩

작은 PNG와 배경을 먼저 표시하고 현재 시간대의 HD WebP를 비동기로 디코드한다.
일반 재생 중인 영상과 접근을 담당하는 `#naeruHd` 이미지는 같은 크롭 상자에 있다.
접근 진행률 4~24% 구간에서 부드럽게 교차 전환하므로 얼굴이 크게 보이기 전에
HD 이미지로 바뀐다. 복귀할 때 반대로 연결하고 일시 정지한 영상을 이어간다.

첫 방문은 마지막 장면 확정부터 HD를 최대 5초까지 기다린다. 이미지가 실패하거나
더 늦으면 이번 방문은 기존 영상으로 진행한다. 접근을 시작한 뒤 늦게 도착한
그림으로 얼굴을 바꾸지 않고 다음 방문에 사용한다.

풍경을 바꾸면 요청 번호로 이전 이미지 응답을 무시한다. 숨김·정지 모드·회전·
장면 전환·복귀에서는 HD/원본의 opacity와 포즈 소유권을 함께 정리한다.

## 검증과 남은 범위

호출 버튼 수정까지 포함해 브라우저 **23개 검사 항목 통과**.
전체 실행 22/23 뒤, 실제 비뉴트럴 구간을 기다리도록 검사 시작 조건을 수정하고
관련 호출 검사 3개를 다시 실행해 모두 통과했다. 런타임은 재검사 전후 동일하다.
런타임 자산 88개·좌표·경로 보호·자산 해시와 인라인 JS 문법도 통과했다.
알파 보간 결과는 저장본과 완전히 일치하며, 밝고 어두운 배경에서도 확인했다.

실제 브라우저에서 원본과 HD를 비교하고, 로딩 실패·지연·오래된 시간대 응답을
검사한다. 정지 모드 32개 풍경, 가을 네 시간대, 접근 네 화면비, 첫 방문과
5분 주기, 동작 중단, 집중 타이머도 전체 회귀 검사에 포함한다.
첫 인사 예약 중에도 수동 호출이 가능하고, 포즈 대기 안내·다른 몸짓의 끼어들기
방지·대기 중 탭 숨김·정지·풍경 변경 시 해제도 확인했다.

영상 전체 316프레임은 기존 해상도다. 고해상도는 근접 뉴트럴 포즈와 정지
화면에 적용했다. 가까운 거리에서도 영상 속 팔·표정을 계속 움직이려면
전체 시퀀스 복원과 VP9·HEVC 알파 재검증이 추가로 필요하다.
Safari·iOS 실제 기기에서의 영상 전환은 이번 Chromium 검사 범위 밖이다.
